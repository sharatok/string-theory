# String Theory — The Fabric of Everything

An interactive, single-page visual explainer of string theory, built with plain HTML, CSS and canvas (no build step, no dependencies).

## Slides

1. **The Universe Is Vibrating**: why point particles break when gravity meets quantum mechanics.
2. **String Energy Signatures**: nine particles (graviton to Higgs boson) shown as animated string vibration modes.
3. **Tune the String**: a playground where you drag out strings, tune frequency, amplitude and tension to change which particle they produce, toggle magnetic poles that deflect charged particles, and watch a Calabi-Yau cross-section visualizer of the extra dimensions.

## Run it

Open `index.html` in any modern browser. Navigate with the arrow keys or the Prev / Next buttons.
